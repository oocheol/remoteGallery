# Frozen MVP interfaces v1

All frontend requests use same-origin /api. Success raw object as listed; errors {error:string,code?:string}. Server establishes local owner HttpOnly cookie on GET /api/session (same-origin local access only); frontend call once before other private endpoints. Public share APIs never establish owner session. All mutations require same-origin and owner cookie. Root page local UI can bootstrap session.

## Artwork presentation updates
`PATCH /api/galleries/:id` accepts optional `artworkStyles: [{id,frameMaterial,frameWidthMm,frameDepthMm,matWidthMm}]` together with `scene`, `placements`, and `expectedRevision`. The revision is mandatory when styles are supplied. Materials are wood/black; dimensions are finite numbers in 0–1000mm. Styles must reference unique artworks in this gallery. Style changes, scene and placements are validated and saved in one transaction. Failed validation changes neither styles nor revision. Older records default to black material and zero mat; zero frame width means no visible frame. Mat adds padding outside image dimensions on all four sides; all geometry, bounds and collisions use full external dimensions. Share snapshots retain the presentation at creation time.
